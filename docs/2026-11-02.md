# Livecall 02.11.2026: Einstieg in Agentic Engineering

## Worum ging es?

Einstieg in **Agentic Engineering**: Ein KI-Agent liest, schreibt und ändert Code direkt in deinem Projekt, statt nur Code-Schnipsel im Chat auszugeben. Als Tool haben wir **Claude Code** verwendet. Die Konzepte lassen sich aber auf andere Agent-Tools übertragen.

## Was wir gemacht haben

1. **Claude Code installiert** und in **VS Code** eingerichtet.
2. **Verschiedene Zugänge zu den KI-Modellen** gezeigt: kostenpflichtige Subscriptions und kostenlose Varianten.
3. **Demo:** Mit Claude Code haben wir im Join-Projekt einen **Dark Mode** ergänzt: https://github.com/TobiasMatthies/Join

## So kannst du es nachmachen

1. Claude Code nach dem [Quickstart](https://code.claude.com/docs/en/quickstart) installieren.
2. Die [VS-Code-Integration](https://code.claude.com/docs/en/vs-code) einrichten.
3. Zugang wählen: eigene Subscription oder die [kostenlose Variante](https://popularaitools.ai/blog/how-to-use-claude-code-free).
4. Ein eigenes Projekt öffnen und Claude Code eine kleine, klar umrissene Aufgabe geben, zum Beispiel einen Dark Mode.
