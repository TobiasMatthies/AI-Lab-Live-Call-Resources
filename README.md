# AI-Lab-Live-Call-Resources

Willkommen! Dieses Repository beinhaltet alle relevanten Ressourcen aus dem **KI Lab Call der Developer Akademie** mit Schwerpunkt auf **Agentic Software Development:**

Hier findest du sowohl Dokumentationen der einzelnen Calls und relevante Call-Ressourcen als auch zukünftige gemeinsame Projekte.

## Wo finde ich was?

| Ordner                                         | Inhalt                                                                |
| ---------------------------------------------- | --------------------------------------------------------------------- |
| [`docs/`](docs/)                               | Zusammenfassungen der einzelnen Calls, sortiert nach Datum            |
| [`projects/`](projects/)                       | (In Arbeit) Die Projekte aus den Calls, ein Ordner pro Projekt mit eigener README |

## So steigst du ein

1. Lies die Zusammenfassung des Calls unter [`docs/`](docs/). Dort stehen auch Links zu Videos und offiziellen Dokumentationen.
2. Öffne das passende Projekt in [`projects/`](projects/) und folge dessen README.
3. Bau das Projekt selbst nach und probiere eigene Varianten aus.
